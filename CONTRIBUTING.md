# Contribuição

## Fluxo

1. Crie uma branch curta a partir de `main`.
2. Faça uma mudança lógica por commit.
3. Use Conventional Commits.
4. Execute `npm test` e as auditorias antes do push.
5. Nunca inclua credenciais ou dados pessoais reais.

## Tipos de commit

- `feat`: funcionalidade
- `fix`: correção
- `docs`: documentação
- `test`: testes
- `refactor`: refatoração
- `security`: segurança
- `a11y`: acessibilidade
- `perf`: desempenho
- `chore`: manutenção
