# Estratégia de testes

## Automatizados

```bash
npm test
```

A suíte cobre navegação, sessão, progresso, questionários, acessibilidade, responsividade, segurança e consistência do produto.

## Manuais

- 360 px, 768 px e 1366 px
- teclado sem mouse
- tema claro e escuro
- movimento reduzido
- sessão expirada
- rede indisponível
- vídeo não incorporável
- duas contas para isolamento por RLS
